# X-Ray Union Maharashtra — Fixes Applied (2026-09-18)

## Member Approval
- Added visible **Approve / Reject** actions for Pending members in the main Member Control table.
- Added the same actions to the Pending Requests modal.
- Approval sets `status: Approved`, `loginEnabled: true`, and records approver/time.
- Rejection sets `status: Rejected`, `loginEnabled: false`, and stores an optional rejection reason.
- Added `member_approve` permission for Sub-Admins.

## Member Search / Status
- Search now covers name, mobile, email, employee ID/number, Sevarth ID, district, mandal, workplace and designation.
- Added Rejected status filter.
- Pending/Approved counts now recognize legacy Marathi status values as well as English values.
- Member table now shows Login Active/Disabled state.

## Login Control
- Admin Login Enable/Disable now actually blocks/unblocks member login.
- Member dashboard no longer trusts a manually edited `localStorage.memberSession`; Firebase Authentication must be present and the member record is reloaded from Firestore.

## Password Security
- Removed the old client-side behavior that only wrote a new password into the member Firestore document.
- Added secure HTTPS Cloud Functions:
  - `adminSetMemberPassword`
  - `masterSetMemberDefaultPasswords`
- Passwords are kept in Firebase Authentication; Firestore `password`/`pass` fields are cleared.
- Admin/master password resets mark `forcePasswordChange: true`.
- Members with that flag are prompted to set a new password immediately after login.

## Cloudinary PDF Search
- Added the missing `cloudinaryPdfSearch` HTTPS Cloud Function used by the Admin Cloudinary PDF Search panel.
- It searches uploaded PDF resources through Cloudinary's authenticated Search API.

## Hosting Deploy
- Existing `firebase.json` Hosting ignore rules are retained to exclude `.git`, `.github`, Android, Functions source and executable/native files from Hosting uploads.
- Removed the stray empty `css/js` file.

## Validation
- `functions/index.js` passes `node --check`.
- Inline JavaScript blocks in the modified HTML files pass `node --check` extraction validation.

## Important deployment step
After uploading this project to GitHub, deploy Hosting and Functions from the project root. The new password and Cloudinary search endpoints do not exist in Firebase until the Functions source is deployed.
