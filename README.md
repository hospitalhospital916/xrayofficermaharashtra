# क्ष-किरण वैज्ञानिक अधिकारी संघटना — Portal + Native Android

This package contains the existing web portal plus a Native Android project.

Key upgrades:
- Secure PDF reader with dynamic watermark
- Native Android FLAG_SECURE + FCM deep links
- Master Admin storage/security area
- 4 MB document/PDF upload allowance
- Smart image compression for larger images
- Cloudinary PDF upload using raw/upload
- Telegram bot token removed from browser code
- Firebase Functions for push, Telegram relay, Cloudinary usage and master cleanup

See `MASTER_ADMIN_SETUP.md` before deployment.
